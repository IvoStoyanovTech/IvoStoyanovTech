# Ivaylo Tech portfolio

Static HTML, CSS, and JavaScript portfolio. No backend, database, credentials, packages, or build required.

The hero includes Strata: a ray-marched WebGL sculpture of nine twisting metallic layers with pointer and keyboard rotation, reset, and motion pause. It limits resolution and frame rate, stops when offscreen or hidden, and includes a 2D perspective fallback when WebGL cannot initialize.

The rest of the site contains six work areas, local colorful technology badges, and a 365-day contribution calendar with lightweight wave animation and accessible daily tooltips. Calendar data is a labeled snapshot ending 10 September 2026; recent profile-repository commits refresh from public GitHub with a fallback. Scroll transitions respect reduced motion.

Private preview: https://ivaylo-engineering.kwoter.chatgpt.site

Serve this directory with any static HTTP server. After merging, GitHub Pages can serve main /docs; publication is not enabled. Google Fonts has local system fallbacks.
